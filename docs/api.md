# Contract API

The unreleased 0.4.0 contracts have separate, self-contained API references:

| Contract | Reference |
| --- | --- |
| `VestingEscrowFactory` | [Factory API](api/factory.md) |
| `VestingEscrowSimple` | [Standard ERC-20 escrow API](api/standard.md) |
| `VestingEscrow4626` | [ERC-4626 escrow API](api/erc4626.md) |

Each page documents the complete external surface, roles, authorization,
amount units, lifecycle behavior, and events for that contract. The
[ERC-4626 accounting guide](erc4626.md) separately derives the principal/yield,
gain/loss, and rounding model.

Version 0.4.0 is unreleased, unaudited, and undeployed. Historical v0.x and
LlamaPay deployments use different ABIs.
